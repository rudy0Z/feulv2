# Feul --- Screen Build Specifications

## Screen 01 --- Home / New Contributor

Purpose: Get a new contributor to their first earning opportunity.

Hierarchy:

1.  Top bar
    -   Feul wordmark
    -   notification
    -   avatar
2.  Greeting
    -   Good morning, \[name\]
    -   Selected language
    -   number of relevant opportunities
3.  First earning module
    -   progress toward ₹100
    -   amount earned
    -   amount remaining
    -   acoustic/waveform visual used meaningfully
4.  State tabs
    -   Today
    -   Available
    -   In review
5.  Next opportunity
    -   title
    -   situation
    -   language
    -   format
    -   duration
    -   total payout
    -   coverage multiplier
    -   CTA
6.  More opportunities
    -   compact task rows

Bottom navigation: Home / Jobs / Wallet

## Screen 02 --- Home / Returning Contributor

Same architecture.

Change the primary state to: - current earnings - active/review state -
next recommended job - resume if session is active

Do not redesign the whole screen for returning users.

## Screen 03 --- Jobs

Header: Find work

Controls: - search - filters

Tabs: All / Lines / Scenario / Interview / Room

Job list: - image or contextual thumbnail - title - short description -
language - format - duration - pay - coverage - save - arrow

Keep rows scannable.

## Screen 04 --- Job Detail

Hero: - contextual image - title - coverage - description

Earnings: - total - base - coverage multiplier - bonus if applicable

Requirements: - language - environment - duration - any required
behavior

Audio: - sample playback

Explanation: - what the contributor will do - what AI/director
provides - what the contributor provides

Primary CTA: Start this job

## Screen 05 --- Studio

Visual priority shifts strongly toward audio.

Show: - task title - situation - progress - current prompt/stem -
waveform - recording state - timer - mic level - stop/pause/re-record
controls

Studio can use the strongest gradient/audio treatment.

Do not use chat bubbles.

## Screen 06 --- Review

Show: - clips ready - waveform/audio thumb per clip - pass/fail state -
playback - retake - submit

## Screen 07 --- Repair

Show: - overall result - passed clips - failed clip - exact failure
reason - example - concise correction tip - retake - later - appeal

## Screen 08 --- Wallet

Top: - available - in review

Secondary: - this week - total

Then: - ledger - withdrawal

Withdrawal CTA should communicate exact remaining amount.

## Screen 09 --- Profile

Show: - standing - reliability - unlocked work - format × language
craft - coverage context - data rights / data vault - revoke/delete

Avoid social-profile aesthetics.
