# A. PRODUCT TRUTH

-   [ ] Product is a gig marketplace for voice-data work.
-   [ ] Contributor is doing real paid work.
-   [ ] AI is infrastructure/director, not the headline.
-   [ ] No chatbot/copilot product surface.
-   [ ] No job-application interview.
-   [ ] INTERVIEW is only a recording format.
-   [ ] Jobs use Available → In-progress → In-review → Settled.
-   [ ] Same work = same base pay.
-   [ ] Total = round(base × coverage multiplier) + bonus.

# FINAL QA QUESTION

If someone only sees the core prototype, can they understand:

**"I choose my language → I consent → I find a real job → I perform it →
I see what passed → I get paid → I can withdraw → I control my data."**

If not, the architecture is not ready for visual execution.
